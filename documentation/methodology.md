# Methodology

This is a synthetic portfolio simulation, not an official humanitarian information product. The generator uses controlled random distributions to create plausible relationships between needs, severity, response, geography, sector and funding.

### Analytical logic
Coverage = People Reached / People in Need
Funding Gap = Requirements - Received
Funding Coverage = Received / Requirements
Priority Index = weighted combination of need pressure, severity pressure and coverage penalty.

The project intentionally includes cases where high need does not automatically produce high coverage, allowing analytical prioritization rather than descriptive reporting only.
