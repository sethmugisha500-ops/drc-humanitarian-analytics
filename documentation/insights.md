# Example Insight Framework

The analysis should answer five executive questions:
1. Where are the largest concentrations of humanitarian need?
2. Which sectors have the weakest coverage?
3. Where is the largest funding gap?
4. Which territories combine high need, high severity and low coverage?
5. Which operational areas appear most cost-efficient?

Do not write conclusions before running the current dataset. The dashboard and README should report findings generated from the actual synthetic data extract, not copied numbers from the visual reference.
